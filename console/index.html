How it works
1

Read

Every 60 seconds, reads each watched position's health factor through KeeperHub.

2

Decide

Below threshold, computes exactly how much debt to repay to reach a safe target, not a fixed guess.

3

Act

Executes the repay through KeeperHub, on-chain, with a real reserve wallet. No local signer.

4

Verify

npm run verify re-derives every claim above from chain data. No API key required.
